# GitHub submission package

**Prepared:** 10 August 2026  
**Policy:** retain source, frozen inputs, manuscript, compact reports, and
auditable summaries; quarantine reproducible or heavyweight runtime material.

## Retained

- the integrated dissertation and supporting methodology documents;
- the 25-area literature-gap closure matrix, primary-source verification set,
  and cross-search summary;
- source code, launch scripts, Slurm templates, tests, and dependency locks;
- frozen configurations, prediction declarations, analysis plans, registries,
  and layout receipts;
- compact JSON, YAML, CSV, Markdown, notebook, and figure outputs needed to
  substantiate reported findings;
- compact Phase 1/1.5/2 summaries copied into the canonical legacy-summary
  package; and
- the completed FreezeShift, latency-amendment, TokenShift-profile, and
  TokenShift-accuracy reports.

## Quarantined locally

- raw COCO, Flickr30k, and qualified CC3M data;
- Python environments, package/model caches, test caches, and graph indexes;
- checkpoints, teacher/feature caches, tensor and embedding exports;
- raw scheduler logs, prediction dumps, diagnostic contact sheets, and the
  development chat transcript.

Nothing was deleted. The first cleanup identified 1,930 paths; the compact
prediction declarations were restored after verification showed that they are
frozen inputs, leaving 1,929 entries in
`quarantine/github_submission_cleanup_20260810/original_paths/`. A post-test
pass moved 26 regenerated bytecode/test-cache paths into
`quarantine/github_submission_cleanup_20260810_postverify/`. The literature
verification pass moved another 26 regenerated cache paths into
`quarantine/github_submission_cleanup_20260810_litverify/`. The ignored,
machine-readable manifests in the dated quarantine directories record every
original path, quarantine path, kind, and reason. Restoration must refuse to
overwrite any path created after cleanup.

Run a dry policy check with:

```bash
python scripts/prepare_github_submission.py
```

The public repository is expected to remain below GitHub's individual-file
limit without Git LFS. Dataset and checkpoint reproduction requires the local
resources or reacquisition steps; scientific findings remain inspectable from
the retained reports.
