# F3 — Confirmatory claim boundary

The existing one-seed dose-response curve is observational because queue
capacity simultaneously changes negative count and feature age. Its
directionality is already known and cannot be newly preregistered.

The confirmatory contribution requires:

1. matched-age tests across batch sizes;
2. three seeds;
3. image-only and text-only queues;
4. actual age logging for both modalities;
5. fixed optimiser-update and evaluation protocols.

Batch size still changes in-batch negative count and must be acknowledged.

Confidence: high.
