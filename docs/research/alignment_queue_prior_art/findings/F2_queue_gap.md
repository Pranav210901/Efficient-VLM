# F2 — The defensible gap is narrow and mechanistic

Cross-Batch Memory establishes that historical embeddings can help when drift
is slow and already ablates memory ratio and batch size. Momentum Contrast
maintains key consistency through a moving-average encoder. Adaptive Cross
Batch Normalization explicitly varies batch size and memory size, reports cases
where ordinary XBM is worse than no memory, and argues that accumulated
features must be kept current.

Therefore neither a generic queue-capacity curve nor a capacity/batch
interaction is new. No directly matching paper in the reviewed corpus studies
modality-separated queue age in bidirectional projector-only alignment between
independently frozen image and text encoders. This is a qualified search
result, not proof of absence.

Confidence: moderate.
