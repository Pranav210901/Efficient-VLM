# Underspecification

- Paper: *Underspecification Presents Challenges for Credibility in Modern
  Machine Learning*
- Venue: Journal of Machine Learning Research 2022
- URL: https://www.jmlr.org/papers/v23/20-1335.html
- Verified evidence: models satisfying the same observed specification can
  behave differently under deployment-relevant stress tests.
- Short excerpt: “underspecification presents challenges for credibility.”
- Relevance: supports narrowing conclusions to the tested training recipe.
