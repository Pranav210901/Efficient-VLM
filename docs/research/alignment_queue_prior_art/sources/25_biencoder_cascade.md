# Bi-Encoder Cascades

- Paper: *Bi-Encoder Cascades for Efficient Image Search*
- Venue: ICCV Workshops 2023
- URL: https://openaccess.thecvf.com/content/ICCV2023W/RCV/html/Honig_Bi-Encoder_Cascades_for_Efficient_Image_Search_ICCVW_2023_paper.html
- Verified evidence: cheap/expensive text-image bi-encoder cascade and measured
  lifetime encoding-cost reductions.
- Short excerpt: “cost reductions by up to 6x.”
- Relevance: closest prior work for an efficient retrieval cascade.
