# Slurm template namespace

Generated and hand-written Slurm templates remain grouped by their historical
implementation family. They are executable definitions, not result evidence.
Compact completed reports live in the corresponding canonical experiment under
[`../artifacts/`](../artifacts/). Raw stdout/stderr is excluded from GitHub and
remains in the recoverable local quarantine.

Do not infer experiment status from the presence of an `.sbatch` file. The
authoritative status is recorded in
[`../experiments/registry.yaml`](../experiments/registry.yaml).
